# Learning Pack: Tech + AI + Compliance + Clinical Essentials

This learning pack is designed to make you an expert operator for healthcare AI products.

Scope:
- Tech systems and software architecture
- AI/ML and LLM product engineering
- Compliance and regulated-market execution
- Essential clinical knowledge needed for safe product decisions

Constraints:
- This is educational material, not legal advice and not medical advice.
- Use licensed counsel for legal sign-off and licensed clinicians for clinical sign-off.

## Target Outcome

After completing this program, you should be able to:
- Design and review production-ready health-tech systems
- Lead AI feature design with measurable safety and quality controls
- Translate compliance requirements into technical controls and evidence
- Collaborate effectively with doctors, lawyers, and engineers

## Time Commitment

- Recommended: `10-12 hours/week`
- Duration: `24 weeks`
- Weekly split:
  - `4h` tech and architecture
  - `3h` AI and evaluation
  - `3h` compliance and clinical safety
  - `1-2h` implementation and reflection

## How To Use This Pack

1. Start with [24_WEEK_CURRICULUM.md](./24_WEEK_CURRICULUM.md).
2. Use [CHEAT_SHEETS.md](./CHEAT_SHEETS.md) during weekly execution.
3. Use [ASSESSMENTS_AND_CAPSTONE.md](./ASSESSMENTS_AND_CAPSTONE.md) every 4 weeks to test progress.
4. Produce artifacts weekly in a local folder such as `docs/learning/artifacts/`.

## Suggested Weekly Cadence

1. `Day 1`: Learn concepts and standards
2. `Day 2`: Read architecture or model docs
3. `Day 3`: Implement a small change in this codebase
4. `Day 4`: Write compliance/safety evidence for that change
5. `Day 5`: Self-review and checkpoint quiz

## Program Outputs (Portfolio Artifacts)

By the end, you should have:
- System architecture diagram and threat model
- Data map and privacy control matrix
- Model card, evaluation report, and monitoring playbook
- Clinical safety policy and escalation protocol
- Incident response runbook and audit evidence set
- Capstone dossier ready for investor, partner, or regulator review
