# Founder Skills to Learn for This Build

## 1) Product and Clinical Safety
- Learn how to write safe decision boundaries for AI-assisted health flows.
- Learn triage severity framing: self-care vs urgent consult vs emergency.
- Learn how to define escalation rules with doctors, not in isolation.

## 2) Telemedicine Compliance Literacy
- Learn the legal model in your launch region before scaling features.
- Learn consent, disclaimer, and data-rights basics deeply enough to challenge assumptions.
- Learn how to work with counsel as a product partner, not just an approver.

## 3) Data and Security Fundamentals
- Learn privacy-by-design patterns and least-privilege access.
- Learn audit logs, retention strategy, and incident response basics.
- Learn security review habits for auth, file handling, and third-party integrations.

## 4) Technical Systems Thinking
- Learn API contracts, event/webhook reliability, and failure handling.
- Learn how to evaluate architecture tradeoffs for speed vs maintainability.
- Learn how to read logs/metrics dashboards and ask the right debugging questions.

## 5) Growth and Distribution
- Learn programmatic SEO mechanics for medical content at scale.
- Learn conversion funnel instrumentation (visit -> symptom check -> consult -> subscription).
- Learn copy testing with strict medical safety constraints.

## 6) Team Operating Cadence
- Learn weekly release discipline: spec, build, QA, rollout, incident review.
- Learn how to define acceptance criteria and non-negotiables for patient safety.
- Learn how to run postmortems without blame and drive corrective action.

## 7) Financial and Unit Economics
- Learn core metrics: CAC, retention, consult margin, subscription churn.
- Learn pricing experiments without harming trust or care quality.
- Learn provider capacity planning for peak demand.

## Suggested Learning Order (First 8 Weeks)
1. Clinical safety + compliance basics
2. Product analytics and funnel metrics
3. Security/data architecture fundamentals
4. Growth and unit economics
